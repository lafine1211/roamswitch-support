# プライバシーポリシー

[English](PRIVACY.md) | **日本語**

_最終更新: 2026-08-27_

RoamSwitch は **Zero Telemetry（テレメトリなし）** を原則に設計されています。

## アプリが送信するもの

**何も送信しません。** RoamSwitch はアプリ自身による外部ネットワーク通信を一切行いません。

- アナリティクス・利用状況トラッキングなし
- クラッシュレポート送信なし
- 広告識別子なし
- バックグラウンドでの常時通信なし

すべてのセキュリティ解析（ネットワーク検知、ポートスキャン、ヘルスチェック、ClamAV
スキャン、リンク診断）は **お使いの Mac 上でローカルに** 実行されます。

## Mac 内に保存されるデータ

RoamSwitch は設定情報（登録済みネットワークのフィンガープリント、ガード設定、許可
リスト、ログ）をローカルに保存します。これらのデータが端末外に出ることはありません。
アプリと Application Support フォルダを削除すれば完全に消去されます。

## DNS 脅威保護について

有効化時（Pro）、未信頼ネットワーク上ではシステムの DNS リゾルバをセキュリティ重視の
パブリックリゾルバ（Quad9 / Cloudflare Security 等）へ切り替え、信頼ネットワーク復帰時に
元の設定へ自動復元します。切り替え後の DNS クエリは **そのリゾルバ** のプライバシー
ポリシーの下で処理されます。RoamSwitch 自身はクエリの記録も送信も行いません。

## 購入について

ライセンス購入は **https://lafine.net/** 上で第三者決済事業者を通じて行われます。
当該取引は Web サイトおよび決済事業者のプライバシーポリシーに従います。ライセンス
認証に常時通信は不要です。

## MCP サーバーについて

同梱の `RoamSwitchMCPServer` は読み取り専用で、設定した MCP クライアントとローカルの
標準入出力のみで通信します。ネットワークアクセス機能はありません。
