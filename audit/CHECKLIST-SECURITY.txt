================================================================================
RoamSwitch Defense & Penetration Verification Checklist (macOS VM)
================================================================================

[PREREQUISITES]
- Host Mac: macOS 13 (Ventura) or later on Apple Silicon
- Target VM: macOS Virtual Machine running via Tart or UTM
- Inside VM: RoamSwitch 1.4.8+ installed & privileged helper approved

--------------------------------------------------------------------------------
PHASE 1: [HOST MAC] VM SETUP
--------------------------------------------------------------------------------
1.1 [ ] Clone and launch macOS VM
        tart clone ghcr.io/cirruslabs/macos-sonoma-base:latest test-mac
        tart run test-mac
1.2 [ ] Obtain VM IP address
        VM_IP=$(tart ip test-mac)

--------------------------------------------------------------------------------
PHASE 2: [INSIDE VM] INSTALL ROAMSWITCH
--------------------------------------------------------------------------------
2.1 [ ] SSH into VM (ssh admin@$VM_IP / pass: admin)
2.2 [ ] Verify Swift command line tools (xcode-select --install)
2.3 [ ] Download and install RoamSwitch.dmg
        curl -sSL -o /tmp/RoamSwitch.dmg "https://lafine.net/downloads/RoamSwitch.dmg"
        hdiutil attach /tmp/RoamSwitch.dmg
        cp -R /Volumes/RoamSwitch/RoamSwitch.app /Applications/
        hdiutil detach /Volumes/RoamSwitch
2.4 [ ] Run `open /Applications/RoamSwitch.app` and approve privileged helper

--------------------------------------------------------------------------------
PHASE 3: [HOST ➔ VM] TRANSFER & RUN SCRIPT
--------------------------------------------------------------------------------
3.1 [ ] Transfer audit script from Host to VM
        scp audit/rs-defense-audit.sh admin@$VM_IP:~/
3.2 [ ] Execute audit script inside VM
        chmod +x ~/rs-defense-audit.sh
        ~/rs-defense-audit.sh all

--------------------------------------------------------------------------------
PHASE 4: [INSIDE VM] VERIFY 5 DEFENSE BOUNDARY RESULTS
--------------------------------------------------------------------------------
4.1 [ ] XPC Client Authorization Boundary (§3) ------------ PASS
4.2 [ ] Packet Filter (pf) Priority & Air-Gap (§4, §5) ---- PASS
4.3 [ ] Port Anomaly & Global Exposure (§6) --------------- PASS
4.4 [ ] MCP Server Read-Only Invariant (§8) --------------- PASS
4.5 [ ] ARP Gateway Monitor & Integrity (§11) ------------- PASS
4.6 [ ] Inspect ~/rs-defense-audit/run-*/report.md
