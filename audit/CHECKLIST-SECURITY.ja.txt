================================================================================
RoamSwitch 防御機構・ペネトレーション検証 チェックリスト (macOS VM)
================================================================================

[前提条件]
- ホスト Mac: macOS 13 (Ventura) 以降の Apple Silicon
- 標的 VM: Tart または UTM で作成した macOS 仮想マシン
- VM 内部に RoamSwitch 1.4.8+ をインストールし、特権ヘルパーを承認済み

--------------------------------------------------------------------------------
フェーズ 1: 【ホスト側】仮想マシン (Tart) の準備
--------------------------------------------------------------------------------
1.1 [ ] VM の作成と起動
        tart clone ghcr.io/cirruslabs/macos-sonoma-base:latest test-mac
        tart run test-mac
1.2 [ ] VM の IP アドレス確認
        VM_IP=$(tart ip test-mac)

--------------------------------------------------------------------------------
フェーズ 2: 【VM 内部】RoamSwitch のインストール
--------------------------------------------------------------------------------
2.1 [ ] VM に SSH 接続 (ssh admin@$VM_IP / pass: admin)
2.2 [ ] Swift コマンドラインツールの確認 (xcode-select --install)
2.3 [ ] RoamSwitch.dmg をダウンロード・配置
        curl -sSL -o /tmp/RoamSwitch.dmg "https://lafine.net/downloads/RoamSwitch.dmg"
        hdiutil attach /tmp/RoamSwitch.dmg
        cp -R /Volumes/RoamSwitch/RoamSwitch.app /Applications/
        hdiutil detach /Volumes/RoamSwitch
2.4 [ ] open /Applications/RoamSwitch.app を実行し、ヘルパーを承認

--------------------------------------------------------------------------------
フェーズ 3: 【ホスト ➔ VM】スクリプトの転送と実行
--------------------------------------------------------------------------------
3.1 [ ] ホスト側から VM へスクリプト転送
        scp audit/rs-defense-audit.sh admin@$VM_IP:~/
3.2 [ ] VM 内部でスクリプト実行
        chmod +x ~/rs-defense-audit.sh
        ~/rs-defense-audit.sh all

--------------------------------------------------------------------------------
フェーズ 4: 【VM 内部】5つの防御境界テスト結果の確認
--------------------------------------------------------------------------------
4.1 [ ] XPC クライアント検証 (§3) ------------------------- PASS
4.2 [ ] パケットフィルタ (pf) 優先度 & Air-Gap (§4, §5) --- PASS
4.3 [ ] ポートアノマリー検知 (§6) ------------------------- PASS
4.4 [ ] MCP サーバー Read-Only 不変条件 (§8) -------------- PASS
4.5 [ ] ARP 整合性 & ゲートウェイ監視 (§11) --------------- PASS
4.6 [ ] ~/rs-defense-audit/run-*/report.md を確認
